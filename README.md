# FlowFault

A read-only, open-source HTML form inspection CLI.

This is the initial repository scaffold. Development for v0.1.0 happens on
`feat/v0.1-workflow-inspector`. The complete README, safety notes and
contribution guide arrive with Stage 04.

Requires Node.js 22+ and Chrome / Chromium.
