How to read these results

Report-based, not live monitoring. The workspace loads JSON reports you select. It does not rescan web pages, submit forms or simulate requests.

Comparable runs only. Inspection comparisons require the same page. Scenario comparisons require the same page, endpoint and fault profile.

Locally processed. Your browser parses file contents in memory. Nothing is uploaded, saved in localStorage or sent to a remote server.
